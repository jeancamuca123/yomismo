# Kit Express de Ventas por WhatsApp — $40.000 COP

**[Ver la página del servicio](https://jeancamuca123.github.io/yomismo/)**

¿Tienes un producto o servicio, pero no sabes qué escribir para venderlo por
chat? Convierto la información de tu negocio en mensajes claros, persuasivos y
listos para copiar en WhatsApp.

## Qué recibes

- Una descripción comercial de tu producto o servicio.
- Cinco mensajes de venta para WhatsApp.
- Cinco respuestas a preguntas u objeciones frecuentes.
- Tres mensajes de seguimiento para clientes interesados.
- Una ronda de ajustes sin costo.

**Entrega:** dentro de 24 horas después de confirmar el encargo.

**Precio:** $40.000 COP. Pago por Nequi al confirmar el encargo.

**Garantía:** puedes solicitar una ronda de cambios durante las 48 horas
siguientes a la entrega.

## Mira una muestra

Consulta el [ejemplo completo para una cafetería](MUESTRA.md) para ver el tipo
de material que recibirás.

## Solicita tu kit

[Abre una solicitud en GitHub](https://github.com/jeancamuca123/yomismo/issues/new?template=solicitud.md&title=Solicitud%3A+Kit+de+ventas)
con la información comercial de tu negocio. Los datos de pago se coordinan
después de revisar la solicitud.

Para comenzar solo necesito saber qué vendes, a quién, el precio y el tono que
quieres usar. No envíes contraseñas, documentos ni datos financieros.
